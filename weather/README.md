# Weather App

A simple weather app built with HTML, CSS, and vanilla JavaScript. Search for a city, pick from autocomplete suggestions, and see the current temperature and conditions. The page background changes with the weather.

**Live demo:** https://weather-app-zahra.vercel.app

## Features

- City autocomplete with debounced requests (Open-Meteo Geocoding API)
- Current temperature and conditions (wttr.in)
- Background changes for sunny, cloudy, rainy, and snowy weather
- Loading state and a friendly error message
- Search with the button or the Enter key
- No API keys required

## Tech Stack

HTML5, CSS3, JavaScript (ES6+, Fetch API, async/await)

## Run Locally

Open the `weather` folder in VS Code and start `index.html` with the Live Server extension.
